# lanchpad

Lanchpad は、Discord を窓口にして LAN 内の PC を操作するための bot です。
名前は LAN と launchpad を組み合わせたものです。

現在は、登録した PC に Wake-on-LAN のマジックパケットを送信するプロトタイプです。

## 起動する

### 準備

- `go.mod` に指定された Go 1.26.10 以降を用意します。
- Discord Developer Portal でアプリケーションと bot を作成し、bot 名を `Lanchpad` に設定します。
- `bot` と `applications.commands` のスコープで、利用する Discord サーバーに bot を追加します。
- 対象 PC の BIOS、UEFI、OS の設定で Wake-on-LAN を有効にします。
- bot は常時稼働する別のマシンで動かし、対象 PC の LAN にブロードキャストを送信できるようにします。

### 環境変数を設定する

リポジトリのルートで、設定例をコピーします。既存の `.env` がある場合はコピーせず、その設定を使ってください。

```sh
cp -n .example.env .env
```

`.env` のトークン、各 ID、対象 PC の設定を実際の値に置き換えます。
編集後、同じシェルで環境変数として読み込みます。

```sh
set -a
. ./.env
set +a
```

`WOL_TARGETS` は `名前=MACアドレス[@ブロードキャスト先IPv4アドレス[:ポート]]` をカンマで区切って指定します。
ブロードキャスト先を省略すると `255.255.255.255:9`、ポートだけを省略すると `9` を使います。
例の `192.168.1.255` は、自分の LAN のブロードキャストアドレスに置き換えてください。

`DISCORD_GUILD_ID` を省略すると、コマンドをグローバルに登録します。
試用時は、利用する Discord サーバーの ID を指定してください。
起動時に、その登録先にあるアプリケーションコマンド一覧を上書きします。

bot は `.env` を自動では読み込みません。
トークンをソースコードや Git に含めないでください。

### bot を起動する

```sh
go run .
```

`Logged in as ...` が表示されたら、Discord でコマンドを実行します。
終了するには `Ctrl+C` を押します。

## Discord で使う

```text
/wol target:desktop
/echo message:hello
/echo message:hello author:true
```

`/wol` の `target` には、`WOL_TARGETS` に登録した名前を指定します。
入力中に対象名の候補が表示されます。
成功時の応答はパケットを送信したことを示し、PC の起動完了は確認しません。
`/echo` は、指定した文章を bot から返す動作確認用のコマンドです。

現時点では、bot 独自のユーザー制限やロール制限はありません。
Discord 側でコマンドの利用権限を制限し、信頼できるメンバーだけが使える環境で運用してください。

## 今後の展望

LAN 内の PC 操作用の窓口として、起動後の状態確認や、WOL 以外の操作を検討しています。
操作を増やす際は、利用者の権限制御や誤操作を防ぐ仕組みも整えていく予定です。
